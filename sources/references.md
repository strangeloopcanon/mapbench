# Judge-only reference sources

MapBench generators never received these images. Judges used them as comparative evidence alongside historical knowledge. A reference map is not treated as an infallible answer or a target design.

The images themselves are not redistributed in this repository. Follow each source page for its current attribution and license terms.

[`reference-manifest.jsonl`](reference-manifest.jsonl) records the acquired comparison copy's dimensions and hash, plus source-file metadata where it was available. MB031 retains its original source for honest provenance even though its redistribution rights were not established; its pixels are excluded from this release.
